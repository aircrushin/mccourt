# 赛事报名文案

## 作品名称

McCourt（麦门法庭）

## 一句话介绍

吃什么吵不明白？交给麦门大法官。McCourt 把多人点餐争论变成一场有真实麦当劳 MCP 证据支持的互动法庭审判。

## 功能简介

一位用户可以创建饭局并录入 1–4 位参与者的预算、口味、饮食目标、饥饿程度和自由诉求。系统通过麦当劳官方 MCP 获取可验证的餐品资料，再由确定性推荐引擎处理预算与偏好约束，最后生成一份幽默的 AI 判决书。参与者可以逐人服判或上诉，最多进行三轮局部重算。

## MCP 使用说明

项目服务端通过 Streamable HTTP 连接麦当劳官方 MCP Server `https://mcp.mcd.cn`，使用环境变量提供 Bearer Token。实际可用工具以运行时动态发现结果为准，系统不会在没有返回字段时编造价格、营养、优惠或供应信息。Live MCP 失败时，页面显示明确错误；Demo 模式会带有清晰的 Demo 标识。

## 创新点

- 将多人点餐冲突转化为有戏剧性的法庭流程
- 把真实餐品证据和可测试的确定性推荐分层
- 上诉只重新计算提出异议的参与者，保留已经确认的结果
- 移动端优先，适合现场演示和多人饭局

## 合规说明

McCourt 是参赛者独立开发的非官方作品。输出仅供点餐参考，餐品、价格、营养和供应状态以麦当劳官方渠道实时结果为准。项目不在公开文件中存放真实 Token 或其他密钥。
