# McCourt 60–90 秒演示脚本

## 0–08 秒：冲突出现

画面打开麦门法庭首页。旁白：

> 三个人点一次麦当劳，能吵出四种人生。有人只想省钱，有人要补蛋白，还有人认为薯条是基本人权。

点击「立即开庭」。

## 08–22 秒：录入饭局

添加小王、小李、小张，分别填写预算、偏好和自由诉求。快速标签展示“我只想省钱”“我想吃肉”“今天必须吃薯条”。

旁白：

> 只要一位用户录入大家的诉求，不用登录，也不用让朋友下载新应用。

## 22–38 秒：真实 MCP 取证

点击「咚！开庭！」。画面出现法槌、法官汉堡和进度文案：正在向麦当劳 MCP 调取证据。

旁白：

> McCourt 会通过麦当劳官方 MCP 查询当前可用的真实餐品资料。价格、营养和供应信息只展示已获取的字段，没有数据就明确标注暂未获取。

## 38–62 秒：判决书

判决书展开，依次出现案件编号、审理意见、每人的推荐、预算和数据来源。

旁白：

> 推荐引擎先处理预算等硬约束，再按口味、目标和饱腹程度评分。AI 法官只负责把结构化证据写成一份有点戏剧性的判决书。

## 62–76 秒：上诉

小张点击“我要上诉”，选择“想换个口味”。只有小张的推荐重新计算，已确认的其他推荐保持不变。

旁白：

> 不服判可以上诉，最多三轮。无法满足时，法庭会解释原因，不拿虚假的商品信息糊弄人。

## 76–90 秒：生效与分享

所有参与者确认，红色印章盖下“判决生效！”。展示复制文字、保存 PNG、系统分享按钮。

旁白：

> 从争论到判决，McCourt 让每个人都能吃到一份有证据的妥协。
